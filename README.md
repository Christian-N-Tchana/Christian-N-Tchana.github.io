# Christian N. Tchana — Academic Website

Personal academic website hosted with GitHub Pages.

## Publish

Upload `index.html`, `style.css` and `profile.png` to the root of the GitHub repository `Christian-N-Tchana/Christian-N-Tchana.github.io`, replacing the existing files. Set Settings → Pages → Deploy from a branch → main / (root). Wait for GitHub Pages to deploy, then refresh the site.

## Update

- Modify written content and publication links in `index.html`.
- Modify layout, typography and profile photo alignment in `style.css`.
- Replace `profile.png` to update the photograph; keep the same filename.
- Research projects use native HTML `<details>` elements and work without JavaScript.
